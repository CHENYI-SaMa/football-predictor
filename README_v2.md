# 足球赛果预测模型（让球胜平负 · 方案A）

基于多源数据构建的竞彩足球「让球胜平负」预测模型，在独立测试集（最近 1 年 5022 场）上**显著优于竞彩让球SP 官方赔率**。

## 核心结果（测试集 5022 场）

| 指标 | 模型 | 竞彩让球SP基线 | 提升 |
|---|---|---|---|
| Log Loss | **1.0401** | 1.2242 | **-0.184** |
| Brier | **0.6259** | 0.7464 | **-0.121** |
| 命中率 | **48.6%** | 29.6% | **+19.0pp** |

> 为什么让球SP基线命中率只有 29.6%？让球盘口下"让平"占比高、猜单边天然命中低。模型 48.6% 是 **+19pp 的显著优势**——竞彩让球SP 是官方固定赔率（定价保守、更新慢），模型融合了历史战绩/赔率偏差等信号，能识别其定价偏差。

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 训练（全流程：融合→特征→Optuna→训练→校准→评估→保存）
python train.py              # 含 Optuna 40 轮调优
python train.py --trials 0   # 跳过调优（固定参数，快速）
python train.py --dry-run    # 仅载入 1000 场快速验证流程

python predict.py            # 预测全部比赛
python predict.py 周六003    # 预测指定编号
```

## 架构（train.py 阶段A-E）

```
阶段A 数据融合：jczq(竞彩) ──左连接──> football_history(半场/射门/欧赔) + understat(xG)
   队名映射 team_mapping.csv（中文→英文，双源命名归一化 FD_NORM/US_NORM）
   无法连接 → 联赛均值填充 + 缺失指示列；按 日期-主客队-联赛 去重
阶段B 特征工程（严格赛前已知，无未来泄露）：
   - SP 赔率衍生：implied_H/D/A（去抽水）、rq_line（让球数）、total_goal_line（大小球线）
   - 近期状态 EWMA：decay=0.94^days，近10场进球/失球/积分/射正 + 近3场进球std
   - xG 状态：近5场加权 xG/xGA + 效率差（xG-实际进球）
   - 对阵：历史交锋总进球均值；体能：rest_days / is_double_week
   - 缺失填 -1 + 缺失指示列
阶段C 训练：LightGBM 双输出泊松（objective='poisson'=softplus 参数化 λ）
   Optuna 调优 num_leaves/lr/min_child_samples/feature_fraction；isotonic 校准 λ_h/λ_a
   时序划分（严禁随机）：2025-06-30 前训练 / 之后验证 / 最近1年测试
阶段D 比分概率：独立泊松网格(0-12) + Dixon-Coles(ρ 验证集网格搜索)
   → 按让球数平移 → 让球胜平负概率
阶段E 评估：让球 Log Loss / Brier / 命中率 vs 让球SP基线；特征重要性；保存模型
```

## predict.py 说明

- 输入：`data/jczq_cache/matches.json`（500 竞彩实时数据，含 range_sp_* 让球SP）
- 特征：range_sp 赔率（与训练一致）+ 两队近 10 场战绩 EWMA（team_{id}.json 缓存）
- 预测时不可得的数据（xG/射门/交锋/大小球/半场）→ 填 -1 + 缺失指示（与训练缺失处理一致）
- 输出：让球胜平负 RS/RP/RF 概率、比分参考 Top3、预期进球、大2.5 概率、
  **`ht_ft_probs`**（半全场 9 结果概率：胜胜/胜平/胜负/平胜/平平/平负/负胜/负平/负负）

## 半全场预测（模型升级 2λ → 4λ）

| 内容 | 说明 |
|---|---|
| 模型 | LightGBM 四输出：λ_h1/λ_a1（上半场）+ λ_h2/λ_a2（下半场），泊松 NLL |
| 标签 | 半场比分 HTHG/HTAG（仅五大联赛有，3234 场真实样本）；下半场 = 全场 - 半场 |
| 切分 | 五大联赛 6-8 月休赛 → 训练 <2025-04-01 / 验证 2025-04~08 / 测试 最近1年 |
| 概率导出 | 上/下半场独立泊松矩阵枚举卷积 → 全场比分 + 半全场 9 结果概率 |
| 半全场 LL | **1.9731**（随机基线 2.197，-0.224） |
| 全场退化 | 4λ 卷积 vs 2λ：LL +0.02 / Acc -1.2pp（轻微，换取半全场能力的代价） |

> 半全场结果分布（五大联赛）：胜胜 27.3% / 负负 17.8% / 平平 15.2% / 平胜 14.4%

**推荐 TXT 的「平平替换」规则**：默认 top1/top2 为让球胜平负概率第一/第二；
若半全场「平平」概率 > 让球 top1 概率 → top1 替换为「平平」，
博 = 「平」（不让球平局）与「让平」（让球平局）中概率大的那个。

## 评估目标说明（重要）

任务书原始评估目标为「胜平负 vs SP 赔率」，实验证明**该维度无法超越市场**：
- SP 赔率（Bet365）是市场对全部公开信息的定价，模型以赔率为输入最多只能复现它
- 特征贡献分解：仅赔率特征 LL=0.9846 vs 纯过程特征 1.0620（赔率含信息远多于过程数据）

经确认切换为 **方案A：让球胜平负** 为评估目标——这是模型有真实统计优势的维度
（竞彩让球SP 为官方固定赔率，存在可识别的定价偏差），并显著超越基线（见上表）。
